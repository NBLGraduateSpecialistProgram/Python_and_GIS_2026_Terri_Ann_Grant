## From Data to Decisions: Applied Data Science & GIS with Python

Note there are two coordinated tracks of workshops, one focused on Applied Data Science (with Python) and the other on Spatial Data Science (with ArcGIS). Both tracks integrate Python and GIS work.

This workshop series is designed to extend the existing Python and data science offerings from Rutgers University Libraries by shifting the focus from introductory instruction to applied, real-world analysis, including end-to-end analytical workflows, policy-focused real-world datasets, and interpretation for decision-making. Registrants who complete either pathway will conclude with a capstone session that helps to prepare a structured, portfolio-ready project output, making this excellent preparation for future data science work and careers.
